Project Name: Film Production Management System (FPMS)

Description:
This project is a comprehensive Database Management System designed to streamline film production workflows. It features a robust multi-user authentication system with specific roles (Admin, Director, Technical Staff, Employee). The system allows authorized users to manage movie projects, organize production schedules, track expenses, and manage cast/crew assignments. Built with a cloud-based PostgreSQL database (Supabase) and a dynamic web interface, it focuses on relational data integrity and real-time management.

Key Features:

Role-based access control and secure login.

Full CRUD operations for movie projects and schedules.

Automated database logic using PL/SQL triggers and procedures.

Statistical dashboards for budget and resource tracking.
